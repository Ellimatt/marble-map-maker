# Marble Map Maker

A standalone local browser editor. It has its own server and files; Marble Race has not been modified.

## Run

From this folder, run `node server.js`, then open http://127.0.0.1:5174.
If npm is available, `npm run dev` does the same thing. No install step is needed: Matter.js 0.20.0 is bundled in `vendor/` (matching the race).

## Build a map

- Choose Rectangle or Circle, then drag on the canvas.
- For a freeform Polygon, click corners in perimeter order and press Enter. Escape cancels.
- Select an object and drag to move it. Edit Width, Height, and Rotation in Properties to resize or rotate.
- Choose Powered rotation and place a pin, or enter its local X/Y coordinates. Speed is degrees per second; negative reverses direction.
- Choose Follow path, then Redraw movement path. Click waypoints and press Enter. Speed is pixels per second; playback can loop or go back and forth. In test mode the object begins at the first waypoint.
- Draw the Start area and Finish line with their tools. Place a start region large enough to hold 24 test marbles without overlap.
- Wheel zooms around the cursor; middle or right drag pans; Fit map restores the full view. Grid snapping uses 10 map units.
- Delete removes the selected shape. Ctrl/Cmd+D duplicates; Ctrl/Cmd+Z undoes; Ctrl/Cmd+Shift+Z redoes.
- Test map runs 24 marbles with pause/restart and a finish counter. Back to editor restores the design layout.
- Save locally stores one map in this browser. Load saved restores it. Export JSON makes a portable file; Import validates a file before replacing the document. New and Import can be undone. Save or export before closing the page.

## Format and runtime

Version 1 JSON contains map ID/name, width/height, gravity, start/finish rectangles, and objects. Positions and sizes use pixels. Angles use degrees. Object positions are centers (polygon vertices are relative to the object's origin). Start/finish X/Y are their top-left corners. Anchors are local to the object, before its rotation. Path points are absolute map coordinates. IDs are stable UUIDs.

`src/map.js` owns validation, document defaults, and simulation-time motion. `src/runtime.js` builds Matter bodies and updates their poses at 120 Hz in the editor. It is intended for reuse by the race adapter. `src/app.js` contains editor interactions, history, canvas rendering, and test orchestration.

Run `node --test` for validation, JSON round trip, off-center rotation, path playback, collision, and polygon geometry tests.

## Current limits / next steps

This is a first working editor. Polygons may have inward corners, but edges cannot cross or touch. Size and angle changes use numeric controls, not drag handles. Free swinging hinges, curved paths, and vertex editing are future additions. Very fast or large moving obstacles can tunnel or push marbles through geometry; the fixed physics timestep reduces but does not eliminate that limitation. All four map edges have permanent boundary walls; only finish-sensor crossings count.

Race integration remains a separate change: the existing race takes JavaScript track modules, not this JSON. A data-to-track adapter must reuse the runtime and be checked against the authoritative race/result pipeline before these maps can be used in actual races. The editor does not publish maps or change official results.

Matter.js 0.20.0 is MIT licensed; its copyright/license notice is retained at the top of `vendor/matter.min.js`.

Editor update: property values display at most one decimal place. Newly drawn walls start at 0 degrees; adjust Rotation in Properties. Drawing a movement path now starts at the selected shape and shows numbered waypoints plus a cursor preview. Use Finish path, Undo point, and Cancel above the canvas (Enter/Escape also work).

Boundary walls are automatic and cannot be selected or deleted. They follow the map dimensions and apply to new and imported maps. Their inner faces sit at the map edges, preserving the full playable area. They are generated by the shared runtime, so no extra objects are needed in exported JSON.

## Cutouts and combined motion

Select a shape, then drag Circle cut or Rectangle cut over the area to remove. Hold Shift while dragging a rectangular cut for a square. Cuts can form holes, edge notches, or split a shape into pieces; all remaining pieces stay attached to the same object. Undo or Remove last cut restores material. Up to 30 cuts per shape are supported. A cut that removes the whole shape is rejected; use Delete shape instead. Existing wall objects still load, but new walls use thin rectangles. Automatic map boundaries remain solid.

Choose Path + rotation for simultaneous movement, with separate Speed px/sec and Rotation degrees/sec controls. The local pin moves with the path. Cuts are stored in local object coordinates and move and rotate with it. Circular cut edges use 64 segments shared between drawing and collisions. The Circle tool now draws a circular drag preview.

Circle and Circle cut use center-out drawing: press at the center and drag to the desired outer edge. The preview and final circle use that same radius in every direction.

Width and Height update the canvas while entering valid values. Press Enter or leave the field to finish; one Undo restores the size before that edit.

## Custom shape library

Use Select, then Ctrl-click (Cmd-click on Mac) to add or remove shapes from the selection. Selected shapes highlight together and can be dragged, duplicated, or deleted as a set. In Custom Shapes, enter a name and choose Save selected shapes. A single shape works too.

The library is stored separately from maps in this browser. Create or import another design, choose an entry, click Place saved shape, and click the map to place the group; Escape cancels placement. Copies preserve spacing, geometry, cuts, colors, angles, pins, speeds, playback, and paths. Paths translate with the objects; local pins and cuts stay unchanged. Each placed object gets a new ID, so editing a copy does not alter the library entry. Placement is undoable.

Library entries persist across page reloads in the same browser and origin. They do not sync to other browsers or computers. Exporting a map includes its placed shapes, but does not export the separate library. The library supports up to 200 named entries; storage failures are reported without claiming a save succeeded.

## Scale and complex shapes

Scale marble places a movable 16 px diameter reference matching test marbles. It is saved with the map and can be included in custom shape groups; it stays fixed and does not collide or count toward race finishes. Oval draws from the center with independent horizontal/vertical radii and editable Width/Height. Polygon supports concave outlines such as L-shapes and stars: click corners in perimeter order and press Enter. Self-crossing outlines are rejected. Ovals and concave shapes support cuts, motion, and the custom shape library.

## Block properties

Select a block to change Block color (picker or hex), Material preset, Bounciness (0–1), and Friction (0–1, where 0 is slippery). These properties are included in map files and saved custom shapes. Test marbles use neutral material settings so obstacle surface settings control their response.

Pass direction makes the block a one-way gate: the arrow shows the allowed world direction (up/down/left/right). A marble approaching in that direction passes; the reverse direction collides. Passing remains allowed until it clears the block. Scale markers remain references only.

Teleport behavior moves the block itself between points, waiting Interval seconds at each point. Set teleport locations uses the path drawing controls. Loop playback on an ordinary path travels to the final point then instantly reappears at the first, with no return segment. Jump velocity is cleared to avoid an artificial collision impulse from the distance traveled. A marble already at the destination can still collide with the arriving block.

## Teleport blocks for marbles

Choose **Teleport block**, then drag on the canvas to draw the block marbles will touch. Select **Choose destination on canvas** in its properties and click the arrival point, or enter **Destination X/Y**. The exit ring and dashed selection line identify the link. The block stays fixed; touching marbles teleport while preserving velocity. A 300 ms simulation cooldown and an exit-before-reentry rule prevent chains when an exit overlaps another teleport block. The destination must be at least 24 pixels inside the map.

This is distinct from **Move block by teleporting**, which moves an obstacle itself. Teleport blocks export as `type: teleporter`, normal `w/h`, fixed motion, and a map-space `destination: {x,y}`. Marble Race accepts these exports and uses the same `marble-teleports.js` contact behavior.


### Cut previews and resizing
Select a block, choose Circle cut, Rectangle cut, or Oval cut, and draw a preview. Drag the preview to position it; use its eight edge/corner handles or the cut properties to resize or rotate it. Confirm cut (or Enter) removes the material; Cancel cut (or Escape) discards the preview. Undo restores a confirmed cut.

In Select mode, selected shapes and start/finish regions have edge and corner handles. Hover an edge for a resize arrow and drag to stretch or shrink. Rotated shapes resize along their own axes; circles stay round. Existing cuts and rotation pins stay in place while the surrounding outline resizes. Scale marbles keep their fixed reference size.

## GitHub Pages

This app runs entirely in the browser, so GitHub Pages can host it without a Node server. Push this project to the main branch of a GitHub repository. In Settings → Pages, set Source to GitHub Actions. The included Test and publish editor workflow runs the tests and publishes only index.html, style.css, src/, and vendor/. The deployment's environment link is the live editor URL.

Saved maps and the custom shape library remain local to each browser and website origin; they are not stored in GitHub. Export maps from the localhost version and import them into the hosted editor to move designs. Placed custom shapes travel with exported maps and can be saved back into the hosted library.
